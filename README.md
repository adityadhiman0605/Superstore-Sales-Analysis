# Superstore Sales Analysis

## 📌 Project Overview

This project focuses on analyzing Superstore sales data using Python to identify sales trends, profitability patterns, and key business insights.

The analysis includes data cleaning, data transformation, exploratory data analysis (EDA), and interactive data visualization using Plotly.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Plotly
- Jupyter Notebook

## 📊 Analysis Performed

- Data Cleaning & Preprocessing
- Sales & Profit Analysis
- Monthly & Yearly Sales Trends
- Category-wise Sales Analysis
- Region-wise Sales Analysis
- Product Performance Analysis
- Sales vs. Profit Analysis
- Order & Customer Analysis
- Data Distribution & Outlier Analysis
- Interactive Data Visualization

## 🎯 Objective

To transform raw sales data into meaningful insights that help understand business performance, identify trends, and support data-driven decision-making.

## 📈 Key Skills Demonstrated

- Data Cleaning & Preprocessing
- Data Manipulation
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Data Visualization
- Business Analysis
- Python Programming

## 💡 Key Insights

- Identified the highest-performing product categories based on sales.
- Analyzed monthly sales patterns to identify peak sales periods.
- Compared regional sales and profitability to identify strong-performing regions.
- Examined the relationship between sales and profit.
- Identified patterns in product and customer performance.
